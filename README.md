# Спортивные мероприятия

Учебная конфигурация «Инфраструктура спортивных мероприятий, календарное планирование и протоколирование результатов» для 1С:Предприятия 8.3. Основная конфигурация поддерживает планирование, регистрацию и протоколы. Подключаемое расширение «Учет явки» добавляет отметки участников, регистр и отчет. Комплект проверен на учебной платформе 8.3.27.1508 для Windows.

## Запуск с демонстрационными данными

1. В окне запуска 1С выберите **Добавить → Создание новой информационной базы → Создание информационной базы без конфигурации**. Укажите новый каталог на компьютере.
2. Откройте эту базу в режиме **Конфигуратор**. Выберите **Администрирование → Загрузить информационную базу** и укажите [файл .dt](Поставка/Спортивные%20мероприятия.dt). Загрузка заменяет содержимое выбранной базы.
3. После завершения загрузки запустите базу в режиме **1С:Предприятие**. Выберите одну из четырех учебных учетных записей. Для проверки расширения войдите как **Организатор** и откройте **Явка → Документы учета явки**.

В PowerShell те же действия выполняют команды из каталога проекта:

```powershell
.\Запуск.ps1 -Mode Restore
.\Запуск.ps1 -Mode Open
```

Каталог по умолчанию – `Локальная база` рядом со скриптом. Укажите `-BasePath` при установке в другой новый каталог и при последующем запуске из него. При нестандартной установке 1С задайте `-PlatformPath` с полным путем к `1cv8t.exe` для учебной версии или `1cv8.exe` для обычной платформы.

## Создание базы из исходников

В новой пустой базе откройте **Конфигурация → Открыть конфигурацию → Загрузить конфигурацию из файлов** и укажите [src](src). Для готовой основной конфигурации используйте **Конфигурация → Загрузить конфигурацию из файла** и выберите [.cf](Поставка/Спортивные%20мероприятия.cf). Обновите конфигурацию базы данных клавишей F7.

Откройте **Конфигурация → Расширения конфигурации**. Добавьте расширение с именем `УчетЯвки` и назначением **Дополнение**. Загрузите в него [файл .cfe](Поставка/Учет%20явки.cfe) или XML из [extension](extension), сохраните и обновите конфигурацию базы данных расширения. Для командной строки используются `/LoadCfg "<путь к .cfe>" -Extension УчетЯвки` и `/UpdateDBCfg -Extension УчетЯвки`. В поставке .dt расширение уже подключено.

Команды для новой демонстрационной базы:

```powershell
.\Запуск.ps1 -Mode Source -BasePath 'C:C\Спорт из исходников'
.\Запуск.ps1 -Mode Config -BasePath 'C:C\Спорт из поставки'
```

Оба режима устанавливают основную конфигурацию и расширение, создают учебные записи и пользователей. При ручной установке из пустой конфигурации последовательно запустите с параметрами `/C СпортДемо`, `/C СпортДемоЯвки` и `/C СпортПользователи`. Последний вызов предназначен для пустого списка пользователей. В рабочей базе с имеющимися учетными записями назначьте прикладные роли вручную.

При обновлении базы из версии 1.1.x сначала сохраните резервную выгрузку. После обновления конфигурации запустите 1С с параметром `/C СпортПереносОборудования`. Варианты из демонстрационного списка получают вид спорта по коду, остальные – по одному виду спорта из истории применения. Для позиций без однозначной истории укажите вид спорта в карточке.

## Работа в 1С

В разделе **Главное** открывается страница **Главная**. На ней доступны команды создания мероприятия, регистрации и протокола, ссылки на календарь, загрузку площадок и рейтинг. В списке текущих и ближайших мероприятий выберите строку и нажмите **Открыть мероприятие** или дважды щелкните строку. **Обновить список** перечитывает расписание.

1. В разделе **Инфраструктура** внесите объект и площадку с вместимостью. У каждой позиции оборудования укажите вид спорта. В разделе **Участники** внесите вид спорта с показателем результата, тренера и спортсменов или команды.
2. В разделе **Соревнования** создайте и проведите мероприятие. Заполните даты и время, формат, лимит и площадку. В таблице с колонками «Оборудование» и «Количество» добавьте нужные позиции и укажите количество. Подбор показывает исправный инвентарь выбранного вида спорта и доступное количество на интервал мероприятия. Запас общий для всех площадок. Для просмотра расписания откройте **Календарь спортивных мероприятий**. Поля отчета позволяют отобрать нужный период, объект, площадку, вид спорта и статус.
3. Пока статус «Запланировано», создайте и проведите документ «Регистрация участников». Для просмотра списка откройте мероприятие и нажмите **Участники**. Заявки можно проводить в календарный день начала или раньше, пока статус мероприятия «Запланировано».
4. В разделе **Результаты** создайте протокол и выберите мероприятие по названию и дате. До указанного окончания можно сохранить протокол кнопкой **Записать**. В таблице можно выбрать отдельного зарегистрированного участника или нажать **Заполнить участниками** для всего списка. Введите результаты. Если участник набрал ноль, отметьте **0 очков**. Нажмите **Рассчитать места**. Для ручного изменения заполните ручное место и причину. После окончания соревнования проведите протокол. Мероприятие автоматически получит статус «Завершено».
5. Для просмотра и печати откройте **Итоговый протокол** из мероприятия. Чтобы сменить мероприятие в протоколе или списке участников, в поле **Мероприятие** нажмите **Показать все**, выделите строку и нажмите **Выбрать**, затем **Сформировать**. Другие отчеты – «Загрузка спортивных площадок», «Список участников соревнования» и «Рейтинг спортсменов».
6. Для отмены проведите мероприятие со статусом «Отменено». Этот статус освобождает интервал, сохраняет регистрацию для истории и исключает итоговые результаты из отчетов. Если снять проведение протокола, завершенное мероприятие автоматически вернется в статус «Регистрация закрыта».

7. В разделе **Явка** откройте «Документы учета явки», выберите проведенное неотмененное мероприятие и нажмите **Заполнить участниками**. Укажите «Явился» или «Не явился» и проведите документ. Пустые отметки отдельно видны в **Явка → Явка участников соревнования**. В отчете выберите мероприятие, нажмите **Сформировать** и переключайте **Таблица** и **Диаграмма**. Те же переключатели есть в пяти основных отчетах.

В демонстрационной базе **Администратор** настраивает пользователей и имеет полный доступ; **Организатор** ведет справочники, мероприятия, регистрации и явку; **Судья** вводит протоколы; **Читатель отчетов** открывает документы и отчеты для просмотра. У учебных пользователей поле пароля остается пустым.

В списках команда **Создать** отображается один раз. Чтобы создать копию, выделите строку и нажмите **F9** или кнопку копирования. Копия открывается для редактирования.
