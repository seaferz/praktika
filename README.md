# Спортивные мероприятия

Учебная конфигурация «Инфраструктура спортивных мероприятий, календарное планирование и протоколирование результатов» для 1С:Предприятия 8.3. Собрана и проверена на учебной платформе 8.3.27.1508 для Windows.

## Запуск с демонстрационными данными

1. В окне запуска 1С выберите **Добавить → Создание новой информационной базы → Создание информационной базы без конфигурации**. Укажите новый каталог на компьютере.
2. Откройте эту базу в режиме **Конфигуратор**. Выберите **Администрирование → Загрузить информационную базу** и укажите [файл .dt](Поставка/Спортивные%20мероприятия.dt). Загрузка заменяет содержимое выбранной базы.
3. После завершения загрузки запустите базу в режиме **1С:Предприятие**. Откройте **Соревнования → Календарь спортивных мероприятий**.

В PowerShell те же действия выполняют команды из каталога проекта:

```powershell
.\Запуск.ps1 -Mode Restore
.\Запуск.ps1 -Mode Open
```

Каталог по умолчанию – `Локальная база` рядом со скриптом. Укажите `-BasePath` при установке в другой новый каталог и при последующем запуске из него. При нестандартной установке 1С задайте `-PlatformPath` с полным путем к `1cv8t.exe` для учебной версии или `1cv8.exe` для обычной платформы.

## Создание базы из исходников

В новой пустой базе откройте **Конфигурация → Открыть конфигурацию → Загрузить конфигурацию из файлов**, укажите каталог [src](src) и обновите конфигурацию базы данных (F7). Для загрузки готового [.cf](Поставка/Спортивные%20мероприятия.cf) используйте **Конфигурация → Загрузить конфигурацию из файла**, затем F7. Чтобы создать демонстрационные записи при первом запуске из пустой конфигурации, задайте параметр запуска `/C СпортДемо`.

Скрипт поддерживает `-Mode Source` для XML/BSL и `-Mode Config` для .cf. Оба режима создают базу в пустом каталоге, обновляют структуру и загружают демонстрационный набор. База .dt уже содержит демонстрацию.

## Работа в 1С

1. В разделе **Инфраструктура** внесите объект, площадку с вместимостью и оборудование. В разделе **Участники** внесите вид спорта с показателем результата, тренера и спортсменов или команды.
2. В разделе **Соревнования** создайте и проведите мероприятие. Заполните даты и время, формат, лимит и площадку. Для просмотра расписания откройте **Календарь спортивных мероприятий**. Поля отчета позволяют отобрать нужный период, объект, площадку, вид спорта и статус.
3. Пока статус «Запланировано», создайте и проведите документ «Регистрация участников». Для просмотра списка откройте мероприятие и нажмите **Участники**. Дата регистрации не должна быть позже начала мероприятия.
4. Для ввода итогов проведите мероприятие со статусом «Регистрация закрыта». После окончания соревнования в разделе **Результаты** создайте протокол, выберите мероприятие и нажмите **Заполнить участниками**. Введите результаты и нажмите **Рассчитать места**. Для ручного изменения заполните ручное место и причину. Проведите протокол. Затем можно провести мероприятие со статусом «Завершено».
5. Для просмотра и печати откройте **Итоговый протокол** из мероприятия. Другие отчеты – «Загрузка спортивных площадок», «Список участников соревнования» и «Рейтинг спортсменов».
6. Для отмены проведите мероприятие со статусом «Отменено». Этот статус освобождает интервал, сохраняет регистрацию для истории и исключает итоговые результаты из отчетов. Для снятия проведения протокола завершенного мероприятия сначала измените его статус на «Регистрация закрыта» или «Отменено» и перепроведите мероприятие.
